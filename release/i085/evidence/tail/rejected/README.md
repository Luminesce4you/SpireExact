# Rejected chain prototype

These two JSON studies belong to their recorded source hashes and original
random-target fixtures, not to the final candidate or its later exhaustive
four-combination goal panel. No native calls were made.

`chain-prototype-overlay.zip` preserves the exact five algorithm/integration
files of that rejected prototype. To reproduce its 160 constructed trials,
copy the final source to a throwaway directory, extract this overlay there,
and run `python tools/i085_tail_study.py --out rejected-study.json`.
Do not apply it to an active/native experiment checkout. This restores the
prototype algorithm, not a bit-identical historical checkout: later unrelated
publisher/report files can change the reported overall source hash. Python
wall times will also vary. `chain-prototype.patch.gz` (decompress before inspecting/applying) is a contemporaneous diff
against the immediately post-removal tree, not promised to apply to later
changes. Production has no `--tail-chains` switch.

The chain method assigned persistent downstream macro edits Luby-sized leases.
It did not consistently improve the targeted complementary-choice cases and
regressed other fixtures. It was removed, not enabled based on its name or
on restart guarantees whose assumptions were absent here.
