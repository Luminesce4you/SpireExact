# 两种信息模式的契约

确定性整图内核仍在 `spire_exact/core.py`；显式有限世界的策略内核在 `spire_exact/information.py`。两者不能凭一个 `is_native` 字段宣称游戏等价。

## 目标

所有策略按 `(通关概率, 期望最终分数)` 字典序比较。确定性预知世界中，概率退化为 0/1。因此任何已知必胜路线优先于失败路线；相同胜率下比较分数。未知世界中，概率来自明确的先验，不是动作估值、蒙特卡洛采样比例或随意设定的信心分数。

游戏最终分数由 native host 调用 `ScoreUtility.CalculateScore`；策略模型中的 `terminal.score` 是模型提供的精确整数。目前尚未把原生最终状态接入这个模型。

## 输入

`spire-information-model/v1` 包含有限 `worlds`。每个世界包含唯一 `id`、精确 `probability`、根 `root` 和确定性 `states`。概率写成整数或 `[分子, 分母]`；拒绝浮点、负数、零分母及总和不为 1 的先验。

每个状态必须具有 `observation`，并包含以下之一：

- `terminal: {victory: true/false, score: 整数}`。终局结果和得分必须是可观察信息。
- `actions: [{action: {…}, to: 状态ID}]`。同一个完整动作只能有一个后继。

未支持节点使用 `complete: false` 和 `reason`，不可当作死亡、终局或空动作集合。无终局且无动作也是未支持边界。

## 隐藏模式

先按照可见观察划分初始先验，再对每个信念状态枚举全部共同动作。动作执行后按新观察分组，并用精确贝叶斯条件化更新后验。不同隐藏世界不会作为玩家可选择的分支。

具有相同观察的潜在状态必须具有相同可见动作菜单；若不相同，输入模型需要把菜单差异包含在观察中，否则拒绝模型。禁止利用真正的世界 ID、下一张抽牌或 RNG 内部状态选择动作。

输出是策略，而非固定动作串。根据 `initial_observations` 找到初始节点，执行该节点动作后，用 `next_observations` 的观察匹配后续节点。不要只以观察文字查找所有策略节点：不同观察历史可能形成不同后验。

信念等价键包含全部潜在 `(世界ID, 状态ID, 约分后的概率)`，采用完整字节相等。模型负责确保状态ID对应完整马尔可夫状态。没有按 HP、金币或概率近似值合并。

## 预知模式

显式指定 `--world`，只保留该确定性世界。潜在状态本身可用于决策，不受隐藏模式的共同动作限制。输入仍有完整先验以便同一案例比较两种模式，但其他世界不影响预知世界的策略值。

## 证明边界

目前对有限无环信念图做完整枚举和反向动态规划。循环、未知语义及预算截断均返回 `INCOMPLETE`，不伪造胜率或上界。确定性原内核能处理有限循环图，不表示当前信念策略内核也能处理循环与无限累计收益。

`proven_optimal_in_model` 只关于给定模型和给定先验。`game_equivalence_verified` 保持 false。策略求解目前没有独立闭图证书检查器；其测试包含信息泄漏反例和 50 个随机一次决策问题与独立期望枚举对照。
