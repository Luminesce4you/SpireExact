## 成对表的四项改动

**等距触发。** 第 1、32、64、96…… 个不同的最终幕第一首领（F1）入场触发表，替代旧的 1/32/128/512 几何节奏。

**内容去重。** 触发时按「牌组 ID 与升级多重集 + 遗物 + 候选牌」比较表内容。与已有表完全相同时跳过，触发点保持，等待后一个入场。这用于避免重复探针费用，不建立完整状态等价，也不剪除真实分支。

**平均合并。** 每张牌的成对增益按完整表等权平均，不再被最新一张表覆盖。不完整表不计，成对信号仍仅影响第三幕 `card_reward` 的 `paired:` 档位。

**加牌支进入联合模型。** 每个完整表的加牌支可生成一行合成排序证据：观察为基础入场加这张牌，F2 使用这一支自己的五个满血样本，F1 借用基础入场的真实结果。基础行必须与来源标签和入场位置唯一对应，否则跳过该表的联合行。行键保留完整基础入场字节和合成后缀，与真实入场区分。

这里将新牌对 F1 的影响按零处理，同表多行相关，部分样本同时进入 `paired:` 档位和联合模型。探针与这些模型行只参与算力排序，不进入真实门模型、检查点、结果缓存或胜利证明。

## F2 就绪度与联合分配

就绪度从已真实到达的 F1 门前状态取得满血 F2 合成样本。第一段五个合法样本，全部失败才申请第二段；至少一场合法胜利为 VIABLE，等待第二段为 PENDING，十场合法败场为 DEAD_AT_FULL_HP。缺失、非法、预算或资源失败保持 UNKNOWN。

DEAD 是重试后放与同关口排序的投入信号，队列没有其他可派修复时仍可派出这些重试。联合精英名额在既有排序与就绪度排序之间交替，保留池、淘汰、族上限、名次权重与探索份额。模型未达到拟合条件时沿用已有 F1 信号。

就绪度默认每 20 个非合成、非缓存原生评估最多派一段，该间隔来自设计估算，尚非已测最优值。原联合模型的拟合阈值与刷新条件继续生效；i082 额外合成行单独计数，模型总行数不能直接读成独立真实入场数。
